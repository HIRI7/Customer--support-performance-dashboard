Customer--support-performance-dashboard

Objective

To analyze customer support operations and identify inefficiencies in response time, workload distribution, and regional performance using a structured dataset.

 Dataset

1) Over 1000+ customer support records
2) Includes call volume, average call rating, gender distribution by region and amount brought in by representatives
3) Data required cleaning and transformation before analysis

Tools & Techniques
Microsoft Excel
1) Power Query – data cleaning, transformation, and preprocessing
2) Pivot Tables – aggregation and summarization
3) Interactive Dashboard Design – dynamic filtering and visualization

 Key Features

1) Built multiple interactive visuals to monitor performance across regions
2) Designed KPI-focused layout for quick decision-making
3) Implemented slicers for interactive filtering to analyze trends by time, region, and workload

 Key Insights

1) Identified peak workload periods contributing to response delays
3) Observed imbalance in call distribution across representatives and different months
4) Detected patterns affecting overall service efficiency
